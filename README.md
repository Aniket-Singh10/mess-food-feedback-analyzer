# Mess Food Feedback Analyzer 🍽️

A machine learning project that analyzes and predicts mess food 
ratings based on quality, cleanliness, quantity, and taste using 
Python and Linear Regression.

## 📌 Problem Statement
Mess food quality varies daily, and students often face 
inconsistency in food quality, cleanliness, and taste.

## 🎯 Objective
To analyze and predict mess food ratings using machine learning 
based on different factors.

## ✨ Features Used
- Food Quality
- Cleanliness
- Quantity
- Taste

## 🤖 Model Used
Linear Regression

## 📁 Project Structure
mess-food-feedback-analyzer/
├── data/           # Dataset files
├── model/          # Trained model files
├── analysis.py     # Analysis script
├── app.py          # Application script
└── README.md       # Project documentation

## ⚙️ Installation & Setup

### Prerequisites
- Python 3.x
- pip

### Install Dependencies
```bash
pip install pandas scikit-learn matplotlib numpy
```

## 🚀 How to Run

1. Clone the repository
```bash
git clone https://github.com/Aniket-Singh10/mess-food-feedback-analyzer.git
cd mess-food-feedback-analyzer
```

2. Install dependencies
```bash
pip install pandas scikit-learn matplotlib numpy
```

3. Run training
```bash
python model/train_model.py
```

4. Run analysis
```bash
python analysis.py
```

## 📊 Output
- Model predicts rating based on inputs
- Graph visualization of feedback

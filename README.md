## 📌 Overview

The **Mess Food Feedback Analyzer** is a Machine Learning project designed to analyze student feedback and predict mess food ratings based on various quality-related factors.

The project helps identify patterns in student satisfaction and provides insights into food quality trends using predictive analytics.

---

## 🎯 Problem Statement

Mess food quality often varies from day to day, leading to inconsistent student experiences in terms of:

* 🍛 Food Quality
* 🧼 Cleanliness
* 🍽️ Quantity
* 😋 Taste

Traditional feedback systems are difficult to analyze efficiently.
This project uses Machine Learning to automate and improve feedback analysis.
